# VegVault-FOSSILPOL Agent Guide

This repository produces the fossil-pollen and age-uncertainty inputs consumed by VegVault.

## Required reading

1. Read `.ai/repository-contract.md` for the binding local data and execution safeguards.
2. If `../VegVault/AGENTS.md` exists, read it and the task-specific canonical files it routes to, especially `.ai/suite-architecture.md`, `.ai/r-coding.md`, `.ai/git-workflow.md`, and `.ai/debugging.md`.
3. If the sibling guide is unavailable, use the local contract and existing repository conventions for narrow, well-scoped work. Ask before broad refactors, expensive reruns, output-contract changes, destructive actions, or release work.
4. For commit-message requests, read `../VegVault/.ai/commit-messages.md` when available; otherwise use the self-contained fallback in `.ai/commit-messages.md`. Inspect the actual changed scope before proposing a message.

Local safeguards remain binding even when the central guide is available. Tool-native files are compatibility adapters and must remain short.
